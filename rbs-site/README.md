# RBS Consultoria Contábil

Site em uma página para a RBS Consultoria Contábil, efeitos de rolagem e contato direto via WhatsApp.

## Estrutura

- `index.html` — marcação e conteúdo do site
- `style.css` — todos os estilos (paleta, tipografia, layout, animações)
- `script.js` — efeitos de rolagem (barra de progresso, revelação de seções, contador animado, tilt do emblema, paralaxe)

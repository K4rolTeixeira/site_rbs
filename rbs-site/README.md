# RBS Consultoria Contábil — Site institucional

Site em uma página para a RBS Consultoria Contábil, com identidade visual baseada na logo (verde-floresta, prata e verde-dourado), efeitos de rolagem e contato direto via WhatsApp.

## Estrutura

- `index.html` — marcação e conteúdo do site
- `style.css` — todos os estilos (paleta, tipografia, layout, animações)
- `script.js` — efeitos de rolagem (barra de progresso, revelação de seções, contador animado, tilt do emblema, paralaxe)

## Como usar

Basta abrir o `index.html` em um navegador — não há build nem dependências além das fontes do Google Fonts, carregadas via CDN.

### Publicar no GitHub Pages

1. Suba os três arquivos para a raiz do repositório (ou para uma pasta `docs/`).
2. Em **Settings → Pages**, selecione a branch e a pasta onde estão os arquivos.
3. O site ficará disponível em `https://<seu-usuario>.github.io/<repositorio>/`.
